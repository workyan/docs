DwellFix Support

DwellFix helps homeowners keep up with recurring home maintenance tasks. If something is not working as expected, use the links below to get support.

Open a support request View privacy policy

Common Questions

  • Missing tasks or incorrect schedules: review your home profile and task intervals, then update the task settings.
  • Completion history looks wrong: check the last completed date on the task detail screen and confirm the task was marked done.
  • Custom task problems: confirm the title, interval, and due date were saved before leaving the edit screen.
  • Unexpected app behavior: force quit the app and reopen it, then try the same steps again.

Support Covers

  • App launch or stability problems
  • Checklist, scheduling, and completion-log issues
  • Questions about task setup or expected app behavior
  • Privacy-related questions

Include These Details

  • Device model and iOS version
  • App version
  • Steps to reproduce the issue
  • Screenshots if the problem is visible on screen
