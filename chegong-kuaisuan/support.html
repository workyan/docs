技术支持

车工快算是一款面向数控车床操作员与车工的离线现场计算工具。这里提供问题反馈方式、常见问题与使用边界说明。

反馈问题

请通过 GitHub Issues 联系开发者。为了更快定位问题，建议在反馈中提供：

  1. 设备型号、iOS 版本和车工快算版本；
  2. 所使用的计算模块，例如圆弧切点、锥度或螺纹速查；
  3. 输入值、单位、操作步骤、预期结果与实际结果；
  4. 必要时附上不含个人或商业敏感信息的截图。
请勿在公开 Issue 中提交真实姓名、电话、邮箱、工件图纸、客户资料或其他敏感信息。

常见问题

是否需要注册账号或联网？

不需要。当前版本没有注册、登录或云同步，核心计算功能可离线使用。

输入和历史记录会上传服务器吗？

不会。计算输入、结果、历史、收藏、备注和偏好仅保存在当前设备本机。详情请查看隐私政策。

如何删除本地记录？

你可以在应用内清除历史记录。卸载应用通常也会删除其 iOS 应用沙盒中的本地数据。

计算结果能否直接用于机床加工？

车工快算提供通用计算与复核参考，不连接机床，也不生成可直接执行的完整 G-code。正式加工前，请结合图纸、工艺要求、刀具补偿、机床与控制器说明进行独立复核。

为什么没有找到某种控制器或工艺参数？

不同机床、控制器、刀具和企业工艺存在差异。当前版本仅展示已支持并经过验证的通用计算；你可以提交 Issue 描述希望增加的场景。

使用与安全说明

本应用是计算辅助工具，不能替代图纸审查、工艺人员判断、机床说明书、量具实测或安全操作规程。请在试切和正式加工前复核单位、坐标方向、半径/直径编程方式、刀尖圆弧补偿与边界条件。

隐私政策

了解本地数据保存、权限与删除方式，请阅读车工快算隐私政策。
