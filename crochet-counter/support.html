Crochet-Counter Support

This page is intended for the App Store support link and review reference.

About the app

Crochet-Counter is a focused crochet row counter and project tracker. It is built for offline use and helps you manage row counts, repeat counts, project notes, and multiple crochet projects without requiring an account.

Frequently asked questions

Do I need to create an account?
No. The current version has no sign-in, registration, or subscription flow.

Is my data uploaded to a server?
No. Project data and counter progress are stored locally on your device in the current version.

Can I use it for multiple projects?
Yes. The app is designed to let you keep separate counters and notes for different crochet projects.

What if my progress seems missing?
Check whether the project was deleted or the app data was cleared on the device. The app does not currently provide cloud restore.

Feedback

If you need help or want to report a bug, use the developer contact shown on the App Store listing. When reporting an issue, include the device model, iOS version, app version, and reproduction steps if possible.

Review notes

The app does not require a test account and does not depend on a backend service. Reviewers can open the app and directly test row counting, repeat tracking, project switching, and note editing flows.
