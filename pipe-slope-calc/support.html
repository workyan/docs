PipeSlope-Calc Support

This page is provided for the App Store support link and general product help for PipeSlope-Calc.

Best way to report an issue

Open a support request in the shared documentation repository:

https://github.com/workyan/docs/issues

What to include

Please include your device model, iOS version, app version, calculator mode, entered values, expected result, actual result, and screenshots if relevant.

Use context

PipeSlope-Calc is intended for field math, quick trade reference, and conversion support. Always verify final measurements and local code requirements before installation.

Frequently asked questions

Does PipeSlope-Calc require an account?
No. Core calculator use is intended to work without login.

Does PipeSlope-Calc work offline?
Yes. Core calculation workflows are intended to work offline.

What can PipeSlope-Calc calculate?
The app is designed to calculate drop from run and slope, slope from run and drop, and convert between inch per foot, percent, ratio, and degrees.

Does the app guarantee code compliance?
No. PipeSlope-Calc is a calculation and reference aid only. Always verify local code requirements, actual field measurements, and installation standards before final use.
