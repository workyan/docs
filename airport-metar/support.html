Airport-METAR Support

Airport-METAR helps users check METAR, TAF, decoded weather, and flight category for airports quickly. If the app is not working as expected, use the links below to get support.

Open a support request View privacy policy

Common Questions

  • Airport not found: verify the ICAO code or try a broader airport name search.
  • Weather looks outdated: reopen the app and check whether the source feed has published a newer report.
  • Widget not updating: confirm the widget is tied to a saved favorite airport and reload the widget timeline.
  • Decoded weather or category looks unexpected: compare the raw METAR text and confirm the report time.

Support Covers

  • App launch or stability problems
  • Airport search, favorites, and widget issues
  • Questions about METAR, TAF, and displayed weather status in the app
  • Privacy-related questions

Include These Details

  • Device model and iOS version
  • App version
  • Airport code involved, if relevant
  • Steps to reproduce the issue
  • Screenshots if the problem is visible on screen

Data Attribution and Disclaimer

Weather data is sourced from public NOAA/NWS aviation weather interfaces. Airport-METAR is an independent app and is not affiliated with or endorsed by the FAA, NOAA, or the National Weather Service.
