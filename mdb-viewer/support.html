MDB-Viewer Support

Support information for MDB-Viewer on iPhone.

Current support scope: MDB and ACCDB table viewing

What MDB-Viewer Does

MDB-Viewer helps you open common Microsoft Access database files on iPhone, browse available tables, inspect row data, and export loaded rows to CSV.

Supported Workflows

  • Open .mdb files from the Files app or iOS document picker.
  • Open common .accdb table data where supported by the app parser.
  • Browse table names and view rows in a mobile-friendly layout.
  • Export loaded rows to CSV for follow-up work in other tools.

Known Limitations

  • MDB-Viewer is a viewer, not a database editor.
  • Encrypted databases may not open.
  • Forms, reports, queries, macros, relationships, and application logic are not displayed as desktop Access objects.
  • Some complex fields, damaged files, very large files, or uncommon database versions may be unsupported.

Troubleshooting

  • Confirm the file extension is .mdb or .accdb.
  • Try opening the file from the iOS Files app instead of another app's temporary preview.
  • If a file does not open, verify it is not encrypted or damaged by opening it in your primary desktop database tool.
  • For critical work, always verify exported CSV data against the original database.

Contact Support

For support requests, bug reports, or privacy questions, open an issue in the documentation repository:

https://github.com/workyan/docs/issues

Please include your iOS version, app version, file type, and a short description of what happened. Do not attach private or sensitive database files to public issues.

Privacy

MDB-Viewer does not collect personal information or upload your database files. Read the Privacy Policy for details.
