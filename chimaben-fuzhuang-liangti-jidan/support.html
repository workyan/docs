尺码本-服装量体记单支持

本页面用于 App Store 支持链接和审核说明。

应用说明

尺码本-服装量体记单是一款面向服装店、裁缝店、量体工作室和个人定制从业者的本地优先记录工具，用于整理客户档案、量体尺寸、订单记单、布料备注和交付信息。应用无需账号登录，当前版本数据默认仅保存在本机。

常见问题

是否需要注册账号？
不需要。当前版本没有登录、注册、订阅或开发者自有后端账户体系。

客户资料和订单数据会上传服务器吗？
不会。当前版本的客户档案、尺寸记录、订单备注和图片附件默认仅保存在本机。

为什么会请求照片权限？
仅在你主动为客户或订单添加参考图片时使用，用于选择布料照片、款式参考图等附件。

为什么会请求写入相册权限？
仅在你主动把导出的客户尺寸卡片或订单详情图片保存到相册时使用。

如何备份数据？
可在应用内导出 JSON 备份文件，再通过系统分享面板发送到微信、邮件或“文件”App 等位置保存。

如何恢复之前的备份？
可在应用内选择导入之前导出的 JSON 备份文件，系统会让你手动选择具体文件。

问题反馈

如需反馈问题，请通过 App Store 页面中的开发者联系方式联系开发者。反馈时建议附带设备型号、iOS 版本、应用版本、问题复现步骤和截图，以便更快定位问题。

审核说明

本应用无需测试账号，也不依赖开发者自有后端服务。审核人员安装后即可直接进入应用，测试客户档案新增与编辑、尺寸记录填写、订单记单、图片附件选择、提醒列表查看，以及 JSON 备份导出与导入流程。
